# Contributing to Sealed Rose SDK

Thank you for your interest in contributing to the Sealed Rose open-source tools and SDKs!

## Code of Conduct

All contributors and maintainers are expected to uphold a respectful, inclusive, and professional environment.

## Getting Started

1. **Fork the Repository:** Create a fork of `derekgallardo01/sealedrose-sdk` on GitHub.
2. **Clone Locally:**
   ```bash
   git clone https://github.com/<your-username>/sealedrose-sdk.git
   cd sealedrose-sdk
   ```
3. **Choose Your Area:**
   - `javascript/`: TypeScript / Node.js SDK
   - `python/`: Python SDK
   - `docker/`: Containerized DFIR triage tools

## Submitting Pull Requests

1. Create a feature branch (`git checkout -b feature/my-feature`).
2. Ensure code follows consistent style and includes relevant documentation.
3. Commit with clear, conventional messages (`feat: ...`, `fix: ...`, `docs: ...`).
4. Push to your fork and submit a Pull Request against `main`.

## Questions & Feedback

For general questions, open a GitHub Discussion or contact [derek@sealedrose.com](mailto:derek@sealedrose.com).
To try the web media verification tool, visit [sealedrose.com/verify-video](https://sealedrose.com/verify-video).
