# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Sealed Rose security team takes the security of our open-source tools and developer SDKs seriously. If you discover a security vulnerability in this repository, please report it responsibly.

### How to Report

1. **Email:** Send details to [security@sealedrose.com](mailto:security@sealedrose.com) or [derek@sealedrose.com](mailto:derek@sealedrose.com) with the subject `[Vulnerability Report] Sealed Rose SDK`.
2. **Details to Include:**
   - Description of the issue and potential impact
   - Reproduction steps or proof-of-concept script
   - Affected components (TypeScript SDK, Python SDK, or Docker container)
   - Proposed remediation (if available)

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours
- **Assessment & Triage:** Within 5 business days
- **Coordinated Disclosure:** We work with reporters to release patches before public disclosure.

Please do not open public GitHub issues for security vulnerabilities.
